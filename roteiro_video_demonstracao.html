Roteiro do Vídeo de Demonstração

0:00 - 0:45

Introdução e Contexto do Projeto

🎥 Ação: Comece com a câmera ligada mostrando seu rosto antes de compartilhar a tela.

🗣️ Fala: "Fala, pessoal! Olá, tutor e avaliadores. Meu nome é Leandro Pereira Dias, e este vídeo é a apresentação prática do meu Projeto Integrador Transdisciplinar em Engenharia de Software II. Eu desenvolvi uma Plataforma de Pedidos Online White-Label completa utilizando PHP 8 com o framework CodeIgniter 4, estruturada rigorosamente no padrão de arquitetura MVC. A ideia central do projeto foi criar uma solução reutilizável e adaptável: o mesmo código-fonte serve perfeitamente tanto para uma lanchonete de frango frito quanto para uma loja especializada em cupcakes, bastando parametrizar a identidade no início."

0:45 - 1:45

Arquitetura de Dados e Wizard Dinâmico

💻 Ação: Compartilhe a tela e abra o navegador na rota /install.

🗣️ Fala: "Entrando aqui na parte prática, o sistema conta com um filtro global de instalação. Se o banco de dados estiver zerado, ele intercepta qualquer tentativa de navegação e joga o usuário direto para este Wizard de 4 etapas. Aqui nós definimos o nome da loja, o segmento de atuação, o número do WhatsApp oficial e os horários de atendimento. Para desenvolvimento local, utilizei um banco leve em SQLite 3, mas toda a estrutura foi modelada via migrations do CodeIgniter. Isso significa que para publicar numa VPS na Hostinger rodando MySQL ou MariaDB, basta rodar o comando de migração sem mexer em nenhuma linha de código. Vou concluir a etapa do assistente para vocês verem ele criando as tabelas relacionais e já nos redirecionando para o painel."

1:45 - 2:45

Gestão Administrativa e Regras de Negócio

💻 Ação: Faça o login e navegue pelas telas do /admin.

🗣️ Fala: "Aqui dentro do painel restrito, temos a visão completa do lojista. O Dashboard exibe um gráfico interativo com Chart.js alimentado em tempo real por cliques, o que permite identificar com facilidade quais produtos estão despertando mais interesse nos clientes. Nós temos o CRUD de categorias, cadastro de produtos com adicionais e a tela de configurações White-Label. Nela, eu consigo trocar a cor primária da marca com um clique e ajustar os horários comerciais. Inclusive, uma regra de negócio essencial: se a loja estiver fora do expediente cadastrado, a aplicação bloqueia o checkout lá no front-end para evitar pedidos em horários indevidos."

2:45 - 3:45

Experiência do Consumidor e Checkout Inteligente

💻 Ação: Vá para a página inicial pública, adicione itens à sacola e abra o carrinho.

🗣️ Fala: "Agora, olhando pelo lado do cliente: a interface foi pensada para ser rápida e limpa. O usuário escolhe o produto, seleciona adicionais e o subtotal recalcula na hora. Seguindo boas práticas de IHC, a sacola tem ações reversíveis: se eu excluir um produto sem querer, o sistema me dá um aviso com botão de desfazer. Indo para o checkout, implementei uma máscara em JavaScript no campo de CEP. Quando o cliente digita os 8 dígitos, a API do ViaCEP busca rua, bairro e cidade de forma assíncrona, deixando o cursor direto no número. Ao escolher o pagamento e clicar em concluir, os dados são salvos no banco e o sistema gera uma mensagem limpa e estruturada, abrindo o WhatsApp oficial da loja prontinho para o envio."
